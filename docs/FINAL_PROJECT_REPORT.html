1. Executive Summary & Problem Overview

Traditional corporate attendance logging mechanisms suffer from acute operational vulnerabilities:

  • Buddy Punching & Proxy Attendance: Static QR codes, shared links, or physical magnetic badges can be trivially photographed, forwarded across messaging channels, or swiped by co-workers.
  • Client Clock Tampering: Mobile apps that trust device system time allow malicious users to spoof arrival times simply by modifying their phone's local time settings.
  • Disjointed Work-From-Home (WFH) Approvals: Informal Slack/email requests result in untracked absences, inconsistent quota enforcement, and manual end-of-month reconciliations for HR teams.
  • Lack of Real-Time Visibility: Legacy punch systems process logs in batch intervals, preventing real-time facility occupancy awareness.

The Solution: VorldX Attendance System

The VorldX Employee Attendance System resolves these challenges through a unified, full-stack, enterprise-grade architecture:

1. Dynamic QR Display Kiosk

Deployed at office turnstiles; generates cryptographic 30-second rotating signed QR tokens with smooth canvas rendering and visual radial countdowns.

2. Authoritative Server Engine

Zero-trust architecture where mobile devices submit only opaque cryptographic tokens. Timestamps, shift compliance, grace periods, and durations are computed exclusively on the server.

3. HR Management Web Portal

A reactive SPA providing real-time WebSocket feeds of office arrivals, employee directory management, configurable attendance policies, WFH approval queues, and tamper-evident audit logs.

4. Employee Mobile App

Built with Expo and TypeScript, enabling instant employee self-registration via simulated OTP verification, camera-based QR scanning, personal monthly attendance statistics, and synchronized WFH applications.

4. Cryptographic Security & Anti-Fraud Engineering

To eliminate proxy punching and clock spoofing, the system implements an uncompromising cryptographic verification pipeline:

  1. Dynamic Signed Challenge Generation: The kiosk requests dynamic challenges signed using HMAC-SHA256(terminalId + nonce + expiresAt, terminalSecret).
  2. 30-Second Rotation with 15-Second Sliding Grace: Tokens expire strictly after 30 seconds. A configurable 15-second grace window accommodates network transmission latencies while permanently blocking stale replay attempts.
  3. Single-Use Nonce & Atomic Consumption: Nonces are consumed atomically in MongoDB via findOneAndUpdate({ nonce, consumed: false }, { $set: { consumed: true } }), ensuring simultaneous punch attempts fail.
  4. Server-Authoritative Clock Evaluation: Mobile clients submit only the opaque token string. Arrival time is stamped using the server's NTP-synchronized clock (Date.now()), rendering client clock manipulation harmless.
  5. Sub-500ms Instant Remote Terminal Revocation: Displays subscribe to the display:status_changed WebSocket channel. If an administrator deactivates a terminal, the screen instantly clears cached secrets and displays a security lockout banner.
